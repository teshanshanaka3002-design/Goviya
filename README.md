# Goviya

Goviya is a mobile application developed to connect farmers, buyers, delivery riders, and administrators through a digital agricultural marketplace.

The application allows farmers to list products, buyers to place orders, delivery riders to manage deliveries, and administrators to manage the platform.

## Technologies Used

- React Native
- Expo
- TypeScript
- Firebase Cloud Firestore
- Firebase Authentication
- Firebase Storage
- AsyncStorage
- Git and GitHub

## Main User Roles

- Buyer
- Farmer
- Delivery Rider
- Admin

## Main Features

- User registration and login
- Product listing and management
- Product browsing and searching
- Shopping cart
- Order placement
- Order management
- Delivery management
- Delivery rider earnings
- User profile management
- Direct messaging
- Complaint management
- Farmer verification
- Admin dashboard

## How to Run the Application

### Step 1 - Clone the Repository

Open Command Prompt, PowerShell, or the VS Code terminal and run:

```bash
git clone https://github.com/teshanshanaka3002-design/Goviya.git

### Step 2 - Open the Project Folder

Move into the project folder:

```bash
cd Goviya
```

You can also open the `Goviya` folder using Visual Studio Code.

### Step 3 - Install Dependencies

Install all required packages:

```bash
npm install
```

Wait until the installation is completed.

### Step 4 - Start the Expo Development Server

Run:

```bash
npx expo start
```

Expo will start the Metro Bundler and display a QR code in the terminal.

### Step 5 - Run the Application on a Mobile Phone

1. Install Expo Go on your mobile phone.
2. Make sure the computer and mobile phone are connected to the same Wi-Fi network.
3. Scan the QR code displayed in the terminal.
4. Open the project using Expo Go.
5. The Goviya application will start on the mobile device.

### If the Application Does Not Start Correctly

Stop the Expo server by pressing:

```bash
Ctrl + C
```

Then restart Expo and clear the cache:

```bash
npx expo start -c
```

Scan the new QR code using Expo Go.
